# 🤖 AI Social Media Content Generator

An AI-powered content generation project built during the **Zenith School of AI Masterclass** using **Python**, **Google Colab**, and the **Google Gemini API**.

The project demonstrates how Large Language Models (LLMs) can simplify social media content creation by generating engaging posts from simple user inputs.

---

# 📌 Project Overview

Creating quality social media content consistently takes time. This notebook automates the process by using Google's Gemini AI model to generate creative and engaging content from a user-provided prompt.

The goal of this project is to understand prompt engineering, API integration, and practical Generative AI workflows rather than simply generating text.

# ▶️ Getting Started

1. Open the notebook in Google Colab.
2. Install the required Python packages.
3. Create your own Gemini API Key.
4. Add the API key to your Colab Secrets.
5. Run the notebook cells in order.
6. Enter your desired content prompt.
7. View the AI-generated social media content.

---

# 🔒 Security

For security reasons, the original Gemini API key has been removed from this repository.

To run this project, generate your own API key and store it securely using **Google Colab Secrets**.
